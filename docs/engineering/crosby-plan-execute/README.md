# Plan execute

## Purpose

Use this skill to carry out requested work from an implementation plan with focused changes and verification.

## When to use it

Use it when:

- you have a plan with defined steps,
- the task is large enough to need sequencing,
- or the user has named a step to implement.

## Core workflow

1. Locate the plan and confirm the requested scope and earlier results.
2. Implement each step with the smallest coherent change.
3. Add tests when they provide useful evidence and run focused verification.
4. Update tracked plan status to match completed work.
5. Continue through the requested scope. Ask for direction when a material choice remains unresolved.

## Good practice

- Keep changes atomic.
- Avoid unrelated fixes or refactors.
- Keep each step small enough to reason about quickly.
- Commit when requested or required by repository instructions.

## Common pitfalls

- Scope creep into nearby issues.
- Making a single step too large.
- Marking a step complete before verification.
- Over-engineering before the minimum viable path is proven.
