# Generate README

## Purpose

Use this skill to produce a clear repository README from the project context and codebase structure.

## When to use it

Choose it when a repo needs a first-pass README or a stronger overview of the project purpose, structure, and setup.

## Inputs

This skill relies on the repo’s project context and technical standards, including the local AI brain and project metadata.

## Workflow

1. Read the project context and standards.
2. Inspect the repository structure and entry points.
3. Summarize the project purpose and architecture.
4. Draft a README with the necessary sections.
5. Keep the document concise and readable.

## Typical README sections

- project title
- overview
- architecture
- tech stack
- getting started
- AI or agent collaboration guidance

## Good practice

- Keep setup steps practical and concise.
- Focus on the repo’s value and how to work with it.
- Include agent usage guidance only where it adds clarity.

## Common pitfalls

- Over-explaining obvious setup steps.
- Adding personal contact information.
- Including fluff or corporate filler instead of clear project context.
