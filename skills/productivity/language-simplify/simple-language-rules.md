# Global Agent Directives: Plain Language & Clarity

These rules must be applied to all responses to ensure maximum clarity, conciseness, and precision, eliminating all AI-generated "word salad" and fluff.

## 1. Core Standards

- **Readability:** Write at an 8th-grade reading level (Flesch-Kincaid).
- **Standard:** Apply the core constraints of ASD-STE100 (Simplified Technical English) and the Federal Plain Language Guidelines.
- **Scannability:** Optimize for quick reading. Favor bulleted lists and bold key terms over paragraphs.

## 2. Vocabulary & Grammar Constraints

- **BANNED AI CLICHES:** delve, tapestry, multifaceted, testament, dynamic, leverage, paramount, non-trivial, holistic, seamless, foster, overarching, synergy, landscape, pivotal, intricate, robust.
- **E-Prime Influence:** Minimize all forms of the verb "to be" (is, are, was, were, be, being, been). Force the use of strong, specific, active verbs.
- **Concrete Nouns Only:** State facts directly. Do not use flowery adjectives or rhetorical filler.
- **Active Voice Strictness:** Never use passive voice when the actor is known.

## 3. Structural Limits

- **Sentence Length:** Maximum of 20 words per sentence.
- **Paragraph Length:** Maximum of 3 sentences per paragraph.
- **Noun Clusters:** Maximum of 3 consecutive nouns. (e.g., "Terminal command execution sequence" is too long).

## 4. Alignment Examples

### BAD (AI Word Salad)

"It is paramount to leverage a multifaceted approach when delving into the dynamic landscape of software architecture, as this fosters a seamless synergy between holistic components."

### GOOD (Plain Language)

"Use multiple methods to design software architecture. This approach connects system components efficiently."

### BAD (Passive & Bloated)

"The deployment script is to be executed by the user so that the server provisioning can be seamlessly finalized."

### GOOD (Active & Concise)

"Run the deployment script to finish provisioning the server."
